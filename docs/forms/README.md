# Forms (print and sign)

Word copies of every form a new organization or family signs. The editable source text is in
`docs/templates/` (Markdown); regenerate the Word files when the wording changes.

| Form | Who completes it | Word file | Source text |
|---|---|---|---|
| Partnership agreement (Schedules A to F) | The organization and vAI | `Partnership agreement.docx` | `templates/PARTNERSHIP-AGREEMENT.md` |
| Parent or guardian consent form, full | Each family of a new learner | `Parent consent form - full.docx` | `templates/PARENT-CONSENT-FORM.md` |
| Parent consent add-on (families who already signed a media form) | Those families | `Parent consent add-on.docx` | `templates/PARENT-CONSENT-ADDENDUM.md` |
| Ghana supplement to the consent form (Ghanaian families sign it with the full form) | Each Ghanaian family | `Parent consent Ghana supplement.docx` | `templates/PARENT-CONSENT-GHANA-SUPPLEMENT.md` |
| Open Mind Africa hand-off checklist (what to complete before enrolling) | Open Mind Africa's leaders | `Open Mind Africa hand-off checklist.docx` | `../onboarding/OPEN-MIND-AFRICA-HANDOFF.md` |
| Data responsibilities agreement | The organization and vAI, where the organization controls its learners' data | `Data responsibilities agreement.docx` | `templates/CONTROLLER-AGREEMENT-TEMPLATE.md` |

| My path card (one page for every family) | Hand out to each family with the consent form | `My path card (Davidson AI Futures Lab).pdf`; `My path card (blank, for partners).pdf` to fill in by hand; `my-path-card-template.html` to edit | web version at `/my-path?code=JOINCODE` shows that organization's child safety officer and can be printed |

Also: `../onboarding/LEADER-GUIDE.md` (one page for every leader) and `../onboarding/Community-Onboarding-Guide.html` (the
complete starting guide). All forms are drafts for a lawyer to check; a fluent speaker should check any
translation before families use it.
